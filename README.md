# taco-performance

Tools for measuring and reporting on [TACo](https://threshold.network/taco) threshold signing performance.

The runnable project lives in [`cohort-perf-tool/`](cohort-perf-tool/README.md) (Node.js / TypeScript): load tests, JSON artifacts, Plotly HTML reports, and CI hooks for daily health checks.

Upstream: [github.com/nucypher/taco-performance](https://github.com/nucypher/taco-performance).
